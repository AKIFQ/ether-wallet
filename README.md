# Ether-Wallet

Ether-Wallet is an open-source project developed as an undergraduate capstone by a team of dedicated students. This project is designed to provide a secure and intuitive interface for managing Ethereum transactions. It allows users to connect their wallets, send Ethereum to other addresses, and interact with smart contracts.

## Features

- **Wallet Connection**: Connect to your Ethereum wallet using MetaMask or other wallet providers.
- **Send Transactions**: Easily send Ethereum to other addresses with real-time transaction status updates.
- **Smart Contract Interaction**: Interact with deployed smart contracts directly from the interface.
- **Transaction History**: View a detailed history of past transactions made through the wallet.

## Technologies Used

This project was built using the following technologies:

- **React.js**: For building the dynamic user interface.
- **Vite**: Used as the build tool for fast development and optimized production builds.
- **Ethers.js**: A library aimed to interact with the Ethereum blockchain and its ecosystem.
- **Tailwind CSS**: For styling and responsive design.
- **Hardhat**: For developing, testing, and deploying smart contracts.
- **Node.js**: As the runtime environment for our backend services.
